# 猫咪档案与专项创作说明

## 优先级与依赖

- 猫咪多照片、出生日期、实时年龄、拟人化档案：P0.5；依赖 P0 猫咪身份。
- GIF 专项创作与猫咪表情专项创作：P1；依赖猫咪档案、照片素材和创作 Skill。
- 猫咪资料仍支持本地预览；专项创作已经接入服务端异步生成任务，客户端只负责提交、轮询和展示结果。

## 猫咪档案

- 创建和编辑都可以从相册多选照片，或用相机追加照片，最多 9 张。
- 每张照片可以设为封面，也可以删除；详情页以图文卡片展示照片、生日、实时年龄、性格、偏好和拟人化角色设定。
- 年龄依据 `birthday` 每次页面展示时重新计算，不再依赖手写年龄；没有生日时保留大致年龄作为兜底。
- 拟人化字段包括角色身份、说话方式和口头禅，并可作为后续聊天和内容生成的角色底座。

## GIF 与表情专项

- 入口：首页 → 猫咪菜单 → GIF & 表情 → 选择专项。
- 素材来源：已有猫咪档案照片、相册新图、相机拍摄；有档案时默认使用当前猫咪的封面照片。
- GIF Skill：眨眨眼、尾巴摇摇、喵一下、懒洋洋翻身。
- 表情 Skill：开心、气鼓鼓、困困、想你、震惊、拒绝加班。
- GIF 通过 `special-gif` 任务调用真实图生视频/动图模型，必须配置 `MEDIA_BASE_URL`、`MEDIA_API_KEY`、`MEDIA_GIF_MODEL`；未配置时明确提示不可用，不再用 CSS 摇摆假装 GIF。
- 表情通过 `special-emoji` 任务调用当前真实图片模型，Skill 会进入服务端提示词；结果文件由 worker 存入私有对象存储。
- 生成结果预览使用小弧度圆角（10rpx），头像、档案照片和普通页面图片不强制套用这个规则。

## 验收指标

- 创建和编辑猫档案均能添加、删除、设置封面照片。
- 有出生日期时，详情页和猫档案列表显示自动计算的年龄。
- 详情页能同时查看图片与拟人化文字资料，并可进入编辑。
- GIF 和表情两个专项都能切换猫档案照片、上传新图、拍照和选择 Skill。
- 生成过程中有等待态，完成后展示模型返回的真实 GIF 文件或表情图片；不再通过前端摇摆、叠字模拟结果；无照片时不可提交。
