# 言喵 AI 短视频功能说明（P0.5）

## 范围

短视频创作是 P0.5 能力，依赖：猫咪档案/参考照片、服务端异步生成队列、视频模型 API Key、COS 私有媒体存储。

用户流程：选择猫咪或上传照片 → 选择猫咪短视频模板 → 选择模型/目标时长 → 提交任务 → 轮询结果 → 预览、保存或分享。

## 模型接入

来源：灵泉 AI 视频模型排行，默认取近 7 天的视频排行前 5：

1. MiniMax H3（`minimax-h3`）
2. 海螺 H3 参考生（`hailuo-h3-cankaosheng`）
3. SD 2.5 满血版按秒（`seedance-2.5-guanfang-anmiao`，火山方舟格式）
4. 海螺 H3 全能参考（`hailuo-h3-quannengcankao`）
5. 视频超分（`video-enhance`，视频输入增强，不作为照片生视频默认模型）

统一服务端适配：

- 统一媒体协议：`POST /v1/media/generate`，轮询 `GET /v1/media/status?task_id=...`。
- SD 2.5 按秒：`POST /api/v3/anmiao/contents/generations/tasks`，轮询同路径的任务详情。
- API Key 只存在服务端 `.env`，小程序不直接请求第三方模型。

## 时长策略

小程序默认目标时长为 3 秒，默认画幅为 9:16，默认清晰度为 768P。

当前排行前 4 个生成模型的上游最低时长为 4 秒，因此服务端会把 3 秒请求透明保护为模型允许的最低值，并把请求时长与实际时长写入任务结果。页面会提示用户，避免误解和重复扣费。

## 内置模板 Skill

- 喵 Vlog：猫咪背包出门、回头挥爪、看向远处，适合生活流短视频。
- 变装走秀：原始状态、平滑变装、迈步回头定格，适合节奏型短视频。
- 喵的午夜电影：深夜窗边、冷暖交错的霓虹与缓慢回眸，默认 5 秒，适合电影质感情绪镜头。

模板示例应使用 `server/public/assets/video-examples/` 的版本化公共资源：首帧 JPG 用作封面，点击预览时只播放 `hls/*/index.m3u8`，原始 MP4 仅用于下载和分享；用户实际生成的视频必须使用 `u/` 私有对象键，不进入静态资源目录。

## 验收指标

- 生成任务必须返回 `jobId`，客户端不保持同步长请求。
- 成功时同时维护原始 `video/mp4` 和可播放的 HLS `m3u8 + ts` 切片；播放器优先走 HLS，下载、保存相册和微信视频分享固定走 MP4，失败/超时退还额度。
- 生成结果绑定当前猫咪 `catId`（无档案时允许绑定为空，但必须有参考照片）。
- 默认时长和私密性在 UI 中可见；模型不支持图片参考时不可被误选为照片生视频模型。
