# 服务端 `.env` 填写指南

文件位置：`server/.env`。它只在后端读取，不能复制到 `miniprogram/`，也不要把内容发到聊天或提交 Git。

## 静态设计资源

小程序源码包只保留页面代码，所有运行时静态资源（设计图片、GIF、GLB、字体、音频、JSON 等）统一放在 `server/public/assets/` 作为版本化源文件。部署脚本会自动执行 `npm run sync:assets`，同步到 COS 的 `static/` 前缀，再由后端 `/assets/*` 路由 302 到 CDN；文件字节不再从业务服务器返回。当前开发环境前端使用 `http://127.0.0.1:3000/assets/`；真机或生产环境继续使用 API 的 HTTPS 域名即可，后端会在 CDN 配好后自动切换。

后续新增静态资源不得直接放入 `miniprogram/` 作为运行时依赖，也不得直接引用 COS 原始域名；提交前确认资源位于 `server/public/assets/`，上线后确认对应 CDN URL 返回 200。

部署服务器时需要同步整个目录，并上传 COS 静态资源：

```sh
rsync -av --delete server/public/assets/ your-server:/www/yanmiao/server/public/assets/
cd /www/yanmiao/server && npm run sync:assets
```

不要把用户原照片和生成作品放进这个公开目录；它们仍然走私有 COS 或开发环境的 `server/.storage/`。

## 本地开发

先复制模板：

```sh
cd /Users/niuxingxing/Desktop/MeWo/server
cp .env.example .env
```

本地 PostgreSQL 已使用默认数据库时，最少填写这些值：

```dotenv
NODE_ENV=development
PORT=3000
HOST=127.0.0.1
PUBLIC_BASE_URL=http://127.0.0.1:3000
JWT_SECRET=这里放一串至少48位的随机字符串
DATABASE_URL=postgres://yanmiao:yanmiao@127.0.0.1:5432/yanmiao
WX_MP_APPID=微信公众平台的小程序 AppID
WX_MP_SECRET=微信公众平台的小程序 AppSecret
AI_PROVIDER=mock
STICKER_MODEL=u2net
STICKER_TIMEOUT_MS=120000
```

如果要启用 OpenAI 创意生图，把服务端配置改成：

```dotenv
AI_PROVIDER=openai
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_API_KEY=只填写到服务端.env，不要放进小程序
OPENAI_IMAGE_MODEL=gpt-image-2.5-sunburst
OPENAI_IMAGE_MODELS=gpt-image-2.5-sunburst
OPENAI_IMAGE_MODEL_LABELS=GPT Image
OPENAI_IMAGE_QUALITY=medium
```

如果使用灵泉 AI 的 OpenAI Images 兼容接口，可把上面的地址和模型替换为：

```dotenv
OPENAI_BASE_URL=https://api.lk888.ai/v1
OPENAI_API_KEY=灵泉控制台创建的 API Key
OPENAI_IMAGE_MODEL=tt-image-2.6
OPENAI_IMAGE_MODELS=tt-image-2.5,tt-image-2.5-token,tt-image-2,tt-image-2.6,tt-image-2.6-guan,minimax-h3-image,muse-image,doubao-seedream-5-5-261028,banana-2.1,banana-2.1-token,tt-image-2-token,banana-pro,banana-2,doubao-seedream-5-0-pro-260628,banana-pro-token,gk-image-2.0,banana-2-token,mj_imagine,vidu-image-2,doubao-seedream-5-0-260128,wan2.7-image,doubao-seedream-4-5-251128,kling-v3-omni,qwen-image,wan2.6-image,kling-v3
OPENAI_IMAGE_MODEL_LABELS=TT Image 2.5,TT Image 2.5 官转,TT Image 2,TT Image 2.6,TT Image 2.6 官转,MiniMax H3 图像,Muse Image,即梦 5.5,纳米香蕉 2.1,纳米香蕉 2.1 官转,TT Image 2 官转,纳米香蕉 Pro,纳米香蕉 2,即梦 5.0 Pro,纳米香蕉 Pro Token版,GK Image 2.0,纳米香蕉 2 Token版,Midjourney,VIDU Image 2,即梦 5.0,万相 2.7 图像,即梦 4.5,可灵 V3 Omni,千问 Image Max,万相 2.6 图像,可灵 V3

```

`OPENAI_IMAGE_MODELS` 是服务端白名单，多个模型用英文逗号分隔；小程序会从 `/v1/meta/config` 读取它们并在 AI 生图时提供选择。不要把 API Key 写入小程序或提交到仓库。

`pet-sticker` 首版仍使用本地 U2NET 抠图和白色描边，以保留宠物原貌；OpenAI Images API 用于漫画、海报、穿搭等创意生图模板。OpenAI 图片接口返回的 base64 图片会由服务端写入私有存储，不会把密钥或图片二进制交给小程序后端以外的客户端。

`WX_MP_APPID` 和 `WX_MP_SECRET` 在微信公众平台「开发 → 开发管理 → 开发设置」中获取。AppID 可以是 `wx...` 开头；AppSecret 只粘贴到 `server/.env`。

本地联调时先把 COS 相关三项留空：`COS_SECRET_ID`、`COS_SECRET_KEY`、`COS_BUCKET`。后端会使用项目里的 `server/.storage/` 模拟私有存储。`PUBLIC_BASE_URL` 必须和后端实际访问地址一致，不能在本地继续保留 `https://api.your-domain.com`。

生成安全的 JWT 密钥：

```sh
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

贴纸模型安装与准备：

```sh

U2NET_HOME="$PWD/.models" .venv-sticker/bin/python scripts/prepare-sticker.py
```

模型准备完成后再启动：

```sh

```

另开终端运行生成 Worker：

```sh

npm run worker
```

## 真机微信联调

`127.0.0.1` 只适合开发者工具和本机浏览器，手机不能访问电脑的回环地址。当前项目已预置生产域名 `api.missmeow.net`；真机需要先把它解析到腾讯云服务器，再在微信公众平台配置 request 合法域名：

```dotenv
NODE_ENV=development
HOST=127.0.0.1
PUBLIC_BASE_URL=https://api.missmeow.net
WX_MP_APPID=你的真实AppID
WX_MP_SECRET=你的真实AppSecret
```

如果使用 COS 直传，再填写私有桶信息：

```dotenv
COS_SECRET_ID=腾讯云子账号SecretId
COS_SECRET_KEY=腾讯云子账号SecretKey
COS_BUCKET=存储桶名称-APPID
COS_REGION=ap-shanghai
# CDN 加速域名（不要填 COS 原始域名）
COS_CDN_DOMAIN=https://static.missmeow.net
STATIC_ASSETS_PREFIX=static
STATIC_ASSETS_FROM_COS=true
# 所有已就绪用户媒体是否走 CDN；需要先完成 CDN 私有桶回源授权
COS_CDN_PUBLIC_MEDIA=true
```

COS 建议只给子账号授予该桶的读写权限。不要为了本地调试把桶改成公开读。CDN 源站需要配置为该 COS 桶，并完成私有桶回源授权；`npm run sync:assets` 会把 `static/` 前缀的对象 ACL 显式设为 `public-read`，品牌素材可匿名回源。开启 `COS_CDN_PUBLIC_MEDIA=true` 后，`u/` 用户媒体也统一返回 CDN 地址，访问控制由 CDN 和业务侧保护方案负责。客户端只访问 CDN 域名或 API 的 `/assets/*` 路由，不直接访问 COS 原始域名。

## 这几个值不要填写到前端

`WX_MP_SECRET`、`COS_SECRET_KEY`、`ARK_API_KEY`、`JWT_SECRET` 只能放在 `server/.env`。小程序端只保留 API 域名，不保存任何服务端密钥。

启动前可用这条命令检查是否仍有空的关键项；它只输出变量名，不输出值：

```sh
awk -F= '/^(WX_MP_APPID|WX_MP_SECRET|JWT_SECRET|DATABASE_URL|PUBLIC_BASE_URL)=/ { if ($2 == "") print "缺少: " $1 }' server/.env
```
