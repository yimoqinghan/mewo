# AI 创作工坊（P0.5）

## 范围

- 登录后即可创作，不要求绑定猫咪档案。
- 普通创作者：文字描述 + 可选参考图。
- 专业创作者：文字描述 + 可选参考图 + 画幅比例 + 负面词 + 生图模型 + 专业补充要求。
- 两种创作者模式的描述框都支持「语音输入」：微信端录音，上传到服务端后转成文字并回填；未识别成功时保留原文并允许重试。
- 内置风格模板：使用普通用户能理解的名称；创作页只展示已启用模板，管理入口进入独立的「风格模板」页面。
- 每个风格模板都展示示例图，用户可点击查看大图，并在独立页面启用/停用模板。
- 白边贴纸不属于本栏目，继续保留为后续独立能力，不在本页展示。

## 额度规则

- 普通创作者每天免费 3 次。
- 每次成功提交任务扣 1 次；生成失败由服务端退还。
- 额度用完后页面提示需要支付；支付能力接入前不伪造支付成功。

## 依赖

- 客户端登录态与 `/v1/meta/quota`。
- `/v1/generations` 支持 `templateKey=ai-image`、空 `catIds` 和可选 `assetIds`。
- `/v1/uploads/sign` 与 `/v1/uploads/:id/complete` 支持 `purpose=voice`，`/v1/transcriptions` 负责把语音素材转成文字。
- 数据库迁移 `004_ai_image_creator.sql`。
- AI worker 支持无猫咪档案、无参考图的文字生图任务。

## 验收指标

- 每次重新进入创作工坊不恢复上次的 prompt、参数和未完成任务。
- 未登录点击主 CTA 会进入登录；登录后才能提交生成。
- 普通模式只需要输入描述即可提交；专业模式能切换比例、负面词和模型。
- 额度为 0 时不发起生成请求，并展示支付提示。
- 风格模板管理页可启用/停用模板，刷新页面后配置仍保留；每个模板均有示例图。
- 示例图必须与模板风格一致，管理页两列展示，点击示例图可放大查看。
- 语音输入可以录音、上传、识别并把文字追加到对应描述框；识别接口异常时展示可理解的错误提示。
