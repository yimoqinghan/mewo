# 宠物照片贴纸（P0）

## 产品契约

用户已选择：原照片抠图＋白色描边。保留宠物原貌，生成透明背景、贴合主体轮廓的 PNG。默认 1024 × 1024；白色轮廓随主体缩放，四周保留透明安全区。首版建议单只宠物、主体完整、背景与毛色有区分的照片。

主链路：首页拍照/相册 → 确认宠物与照片 → 一键生成 → 保存相册/分享图片。作品默认私密，生成内容绑定 `catId`。使用服务端本地抠图模型，不将照片发往第三方生图服务。

## 接口、状态和费用

依赖自建 HTTP API + PostgreSQL + Worker + 私有 COS；本地联调使用现有开发存储驱动。遵循当前 AGENTS.md，不使用微信云开发。历史云开发文档不适用于此功能。

- `POST /v1/uploads/sign` → 客户端直传 → `POST /v1/uploads/:id/complete`。
- `POST /v1/generations`：`templateKey: pet-sticker`、单个 `catIds`、单个 `assetIds`、`requestKey`。相同用户/幂等键返回同一任务，消耗 1 次额度。
- `GET /v1/generations/:id`：`queued/running/succeeded/failed/canceled`，成功结果含透明 PNG 临时签名地址。
- `POST /v1/generations/:id/cancel`：仅排队可取消；最终失败/取消退还一次额度，流水记录。
- `GET /v1/works/:id` 获取新签名；`POST /v1/works/:id/save` 主动收藏。

错误态：`QUOTA_EXCEEDED`（次数用完）、`INPUT_MISSING`（缺照片）、`STICKER_UNAVAILABLE`（模型/运行环境缺失）、`NO_SUBJECT`（未找到清晰主体）、`INVALID_IMAGE`（不可解码/尺寸超限）、`STICKER_TIMEOUT`（处理超时）、`GENERATION_TIMEOUT`（客户端等待超时，保留任务继续查询）。错误不可用原图伪装成功。

照片用于抠图，生成结果和输入素材默认私密。点击生成表示同意将本张照片上传用于处理；未经点击不上传。保存相册遵循系统权限；拒绝后由用户主动打开设置。图片分享菜单由用户选择接收方，不创建公开作品链接。

## 依赖与启动

Python 3.11/3.12、`server/requirements-sticker.txt`、预下载的 ONNX 模型。模型只在安装时下载，任务处理中禁止临时联网下载模型。模型及虚拟环境不提交仓库。

```sh
cd server
python3.12 -m venv .venv-sticker
.venv-sticker/bin/pip install -r requirements-sticker.txt
U2NET_HOME="$PWD/.models" .venv-sticker/bin/python scripts/prepare-sticker.py
npm run migrate
npm run dev
# 另一个终端
npm run worker
```

默认开发地址为本机 `http://127.0.0.1:3000`；开发者工具使用开发登录。真机须配置可访问的 HTTPS API/COS 域名、微信登录凭据和正式登录方式。生产配置不允许开发登录。分享/相册权限需在真机验收。

## 验收指标

1. 首页已选照片直接带入创作页，不再选一次；每次结果绑定提交时的猫咪。
2. 有背景的输入实际去除背景；透明输入保留原 alpha；输出含透明区、白色外描边及原宠物像素。
3. 重复提交只扣一次，失败和排队取消退款留痕；页面隐藏/返回后恢复原任务。
4. 相册保存下载真实 PNG；作品库可再次查看和保存；图片分享不会把私有作品改为公开。
5. 加载、网络错误、额度不足、无主体、拒绝相册权限均有可操作反馈。
6. 小屏不遮挡主按钮，首页原有角色和布局保留；创作/结果页继承同一品牌素材与色彩。
