# 喵档案扫码分享（P0.5）

## 目标

用户在“喵卡片”上生成微信官方不限量小程序码。被分享者扫码后进入 `pages/cat-profile/cat-profile`，通过 `scene` 短码读取该猫咪的公开档案详情。

## 接口

| 方法 | 路径 | 鉴权 | 说明 |
| --- | --- | --- | --- |
| POST | `/v1/cats/:id/share-qr` | 必须登录 | 校验猫咪归属，创建 180 天有效的随机短码，调用微信 `getwxacodeunlimit`，返回 `qrDataUrl` |
| GET | `/v1/cats/public-share/:code` | 公开 | 校验短码、有效期和归档状态，返回公开档案快照与头像临时访问地址 |

二维码固定落到 `pages/cat-profile/cat-profile`，只把短码放入 `scene`，不把猫咪 UUID、用户 ID 或档案内容放进二维码。开发/体验版使用 `WX_MP_ENV_VERSION=trial`，正式版设置为 `release`。

## 客户端行为

- 登录用户打开喵卡片时请求二维码，并把服务端返回的 base64 图片写入小程序用户目录。
- Canvas 在二维码中心叠加已生成的言喵猫咪品牌图，中心图控制在安全区内，不覆盖定位点。
- 未登录或微信配置未就绪时，喵卡片仍可生成、保存和分享，但提示“登录后可生成可扫码的小程序码”，不伪造不可用的二维码。
- 扫码进入详情页后不读取扫码者本地猫档案，直接使用公开接口展示分享者主动公开的资料。

## 隐私与撤回

- 猫咪资料默认私密；只有用户主动生成分享码才创建公开快照入口。
- 当前公开快照包含名称、基础信息、性格、偏好、人格设定和头像；不包含账号信息、其他猫咪、私密聊天、作品列表或原始上传记录。
- 分享码默认 180 天失效；后续可在档案管理页增加“撤回分享”并写入 `revoked_at`。
- 微信接口调用只在服务端完成，AppSecret 不进入小程序包和客户端请求。

## 错误态

| 情况 | 客户端提示 |
| --- | --- |
| 未登录/本地档案 | 登录后可生成可扫码的小程序码 |
| 微信 AppID/Secret 未配置 | 扫码入口暂时不可用，喵卡片仍可保存 |
| 短码过期/被撤回 | 喵档案分享已失效 |
| 头像签名地址不可用 | 详情页使用言喵默认猫图，文字档案仍可查看 |

## 验收指标

- 登录用户生成喵卡片时，二维码返回并成功写入临时文件的成功率 ≥ 99%。
- 微信扫码后 3 秒内显示喵档案首屏，短码过期能稳定展示失效态。
- 二维码中心图不遮挡定位点，真机扫码成功率 ≥ 98%。
