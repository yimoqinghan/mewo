# 首页设计稿交互实现记录

## 范围与优先级

- 优先级：P0
- 页面：`miniprogram/pages/index/index`
- 目标：把设计稿的三种首页状态拆成可维护的小程序图层，并形成“摸猫 → 反馈”“上滑/点击箭头 → 玩法菜单”“拍照/相册 → 照片预览 → 创作页”的首版闭环。

## 图层拆分

- 背景：天空使用 WXSS，云朵和底部粉色/黄色地形色块使用独立透明 PNG 图层，太阳和装饰仍保持独立 WXSS 图层。
- 品牌：`assets/design/official-logo.png` 单独作为 Logo 资源。
- 角色：`cat-home.png`、`cat-touch.png`、`cat-menu.png` 分别对应首页站立、触摸反馈、菜单探头状态；当前首页先使用独立平面透明图层完成设计稿还原，3D GLB 资产保留但暂不参与首屏渲染。
- 操作：顶部语音/消息、底部相册/拍照/聊天、上滑入口、菜单列表均为独立 WXML 控件。
- 照片：使用微信 `wx.chooseImage`，预览弹层不上传、不持久化真实照片。

## 依赖关系

- 依赖现有首页路由、`utils/storage.js` 的当前猫咪初始化和现有 `/pages/create/create` 创作页。
- 角色 PNG 为设计稿参考生成的本地视觉资源，不依赖线上图片地址；3D 形态另有三套独立 GLB，不使用整张设计稿作为贴图。
- 真实上传、AI 生成、分享和语音服务仍按项目开发文档保持占位或本地演示。

## 验收指标

1. 微信开发者工具可重新编译，首页无本次改动引入的编译错误。
2. 点击猫咪进入触摸态，出现气泡、触摸手和触摸反馈；再次点击猫咪回到首页态，不自动打断用户交互。
3. 点击上滑箭头或向上滑动进入菜单态，向下滑动或点击菜单把手收起。
4. 菜单入口可触发拍照、创作页跳转、聊天提示和云上家占位提示。
5. 设计稿中的品牌、主角色、背景色块、底部拍照主 CTA 和菜单五项均不是整张截图背景。
6. 私密照片默认只在本次页面状态中预览，未接入云端上传或公开分享。

## 动态角色方案

- 优先级：P0.5
- 方案：最终资产使用 Blender 独立建模并导出 GLB，小程序端使用 `threejs-miniprogram` 官方适配器渲染；猫咪拆成身体、头部、耳朵、眼睛、眼镜、耳机、四肢、尾巴、项圈和黄色背包等独立节点，未把整张设计图放进 canvas。可重复生成脚本为 `tools/blender/build_yanmiao_cat.py`，它只把设计稿角色作为 Blender 前视校准参考，不会将图片打包成运行时表面。
- 交互：当前平面版使用独立状态图叠层、淡入淡出、连续呼吸/轻摆动、气泡入场和触摸手反馈；后续恢复 3D 后再接入独立的抬爪、闭眼、吐舌 GLB。菜单态仍保留独立胸像图层。
- 依赖：`miniprogram/libs/threejs-miniprogram.js` 为适配器内置 Three.js 运行时，`miniprogram/libs/gltf-loader.js` 为兼容 r108 的本地 GLB loader，`utils/cat3d.js` 按 `home/touch/menu` 状态分别加载 `assets/models/yanmiao-cat.glb`、`assets/models/yanmiao-cat-touch.glb`、`assets/models/yanmiao-cat-menu.glb`。
- 3D 资产链：Blender 工程脚本已加入独立 UV、材质族贴图和 `YNM_CAT_RIG` 骨架；下一次成功导出的 GLB 将包含 `YNM_IDLE`、`YNM_TOUCH`、`YNM_WAVE` 动画片段，由 Three.js `AnimationMixer` 播放，拖动仍由 GLB 根节点做横向旋转。

## Blender 资产交付约束

- 优先级：P0.5；依赖 Blender 4.x/5.x 本机执行脚本并导出 GLB。
- 交付物：三套可继续编辑的 Blender 文件和三套运行时 GLB：`art/yanmiao-cat*.blend`、`miniprogram/assets/models/yanmiao-cat*.glb`；首页正面比对预览为 `art/yanmiao-cat-preview.png`。
- 约束：身体、头部、耳朵、眼睛、眼镜、耳机、尾巴、脚趾、项圈、背包、挂件和胡须必须是可编辑的独立几何体；禁止用整张设计图作为猫模型或 canvas 贴图。
- 对比：用每种形态的设计稿正面和对应转面参考作为 silhouette、眼睛/眼镜/耳机/背包/抬爪/面板边缘的位置标定；每次导出前在 Blender 正面相机渲染预览，逐项检查比例、遮挡关系和负空间。后两种形态的侧面/背面目前是基于正面设计稿推导的制作参考，不能声称单张正面图已经能够推导出背面“百分百”形态。
- 验收指标：正面轮廓与参考图逐点对齐；左右拖动能连续绕 Y 轴旋转；点击至少触发 idle、pet、wave 三种反馈；GLB 中保留独立节点和 idle 动画，运行时不依赖整张参考图。开发者工具实测 GLB 解析成功、当前无运行时错误。

## Three.js 验收指标

1. 当前首页主角色使用独立透明 PNG 图层，保证设计稿优先还原；3D GLB 仍保留在项目中，待平面视觉验收后重新启用。
2. 点击 3D 猫咪会在 home/touch 之间切换，使用 `yanmiao-cat-touch.glb` 触发抬爪、闭眼、吐舌、呼吸和头部反馈；打开菜单使用 `yanmiao-cat-menu.glb`。
3. 三种形态的当前 GLB 都由 Three.js 绕自身竖轴连续旋转，拖动方向与视觉方向一致，可查看侧面和背面。
4. 3D canvas 透明叠加在已拆分背景之上，不遮挡底部拍照 CTA、顶部按钮和菜单交互；未把整张设计稿作为背景资源。
