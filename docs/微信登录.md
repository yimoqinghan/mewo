# 微信一键登录（P0）

2026-11-10：当前阶段使用微信身份登录，不要求填写或授权手机号。依赖现有自建 HTTP API、PostgreSQL、真实微信小程序 AppID 和服务端 Secret；不使用微信云开发。

## 登录与账号

- 用户同意账号与隐私说明 → 点击“微信一键登录” → 同步宠物资料并返回。按钮有加载、重复点击保护和失败重试。
- 页面调用 `services/api.js`，由 `adapter.login()` 获取临时 code，提交 `POST /v1/auth/wechat/miniprogram`，请求体只需 `{ code }`。
- 服务端通过微信验证 code，以 `wechat_mp + openid` 关联账号；客户端保存服务端返回的 access/refresh token。未配置微信凭据时不能完成真实登录。
- 本次登录不采集手机号。同一小程序内同一微信身份再次登录可恢复原账号资料；不同平台不自动合并。现有经过验证的手机号绑定与跨端合并接口保留，手机号仍是唯一跨端合并键。
- 登录状态以有效会话和账号为准，建档、上传、贴纸生成不要求 `phoneBound`；接口仍校验 token、账号状态、资源归属和生成额度。照片及作品默认私密。

## 验收

1. 登录页没有手机号输入框和 `getPhoneNumber` 授权按钮；未同意说明不能提交，登录期间不能重复提交，失败后可重试。
2. `phoneBound: false` 的微信账号能同步、新建、编辑宠物档案，并完成上传、生成和保存；生成仍扣额度。
3. 同一微信身份退出后重登可以找到原档案；未登录请求被拒绝，其他账号不能读取或修改其资料。
4. 微信登录配置缺失、登录失败、网络异常有明确提示，不伪造登录成功。

回归命令：`node server/scripts/login-client-test.cjs`；在隔离开发 API/Worker 上执行 `BASE=http://127.0.0.1:<测试端口> node server/scripts/identity-test.mjs` 和 `server/scripts/smoke.mjs`。后两项使用开发身份模拟，真实微信 code 换取仍需开发者工具/手机联调。

部署需同时更新小程序和自建后端，否则旧后端的手机号限制仍会拦截写操作。
