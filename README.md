# 言喵微信小程序

言喵是一个以猫咪身份为基础、以 AI 创作为入口的人猫关系创作产品。首版主链路是：管理多只猫咪 → 选择当前猫咪 → 拍照/上传 → 生成异形或创意猫咪作品。

## 快速开始

1. 安装并打开微信开发者工具。
2. 导入当前目录 `/Users/niuxingxing/Desktop/MeWo`。
3. 使用项目根目录中的 `project.config.json`，将 AppID 替换为自己的小程序 AppID。
4. 编译运行，先体验首页、猫咪档案、拍照创作和作品库的模拟闭环。

## 当前技术栈

- 原生微信小程序
- JavaScript
- WXML + WXSS
- 微信本地 Storage 作为未配置云环境时的回退数据层
- 微信·云开发作为第一阶段服务端、云数据库和云存储
- `miniprogram/services/generator.js` 作为 AI 生成服务的占位层
